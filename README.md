# 50 级明尊琉璃体计算器

基于原 jx3dps-online-public 工程，沿用原入口、React/Redux、Ant Design 配装器、奇穴/秘籍抽屉和计算结果组件，只保留明尊琉璃体心法。数值和技能公式取自 [Generator](https://github.com/J3junluoyu/Generator)，来源版本与计算边界见[模块说明](src/心法模块/心法/明尊琉璃体/README.md)。

## 本地运行

```powershell
pnpm install --frozen-lockfile --ignore-scripts
pnpm dev
```

访问 http://localhost:3000/。配置保存在原项目的本地方案中；同一浏览器地址下的旧明尊配装、气劲、奇穴、秘籍与命中次数会在首次加载时迁移，已有原项目方案不覆盖。

## 检查与构建

```powershell
pnpm test
pnpm typecheck
pnpm build
```

构建产物位于原项目的 `build/`。`pnpm build:local` 生成直接进入明尊的本地静态版本。

配装器保留1110品及以上的明教/通用带加速防御装备和精简内攻装备。附魔、陆级五彩石沿用已确认的过滤规则；五彩石使用三层联动选择，守护·固本·健体作为特例保留。主副T在基础设置中切换，次数在“技能次数 / 增益”中设置。内置用户提供的300秒基础循环，武伤与大漠刀法使用外功属性。戒火斩读取考拉提供的1～11档原始公式，950体质起使用第11档。

“招式产生威胁”在角色和配装器面板独立显示装备原始属性值。原增益框架已接入考拉的药品、食品、攻击磨石、家园酒、指定宴席、创意料理及门派增益；增益统一受“启用增益”控制，勾选“增益面板”可查看生效后的属性。常用药食和磨石每种属性只提供较高两档，属性数值以高档金色、低档紫色显示。家园酒提供女儿红（加速）和玉露酒（御劲）的原酒、今朝醉、六日醉、旬又三四档，依次为23、46、69、92点，八项共用一个单选位置。

## 奇穴格式

前三层固定为圣浴明心、怜世人、极本溯源；第四至第六层各选一项。净身明礼、血泪成悦、驱夷逐法、炽炎镇恶、月尽天明、斩火放入独立混池，最多选三项。极本溯源与主副 T 气劲自动联动。
