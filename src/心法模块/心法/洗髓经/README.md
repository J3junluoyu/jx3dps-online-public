# 洗髓经计算器

首页可选择明尊琉璃体或洗髓经，右上角图标也可切换心法。两者共用基础设置、角色属性、配装器及伤害结果界面，配装与增益缓存按心法隔离；洗髓招式和伤害结算使用自己的数据。

## 数据与固定设置

招式、奇穴、增益及秘籍来自考拉 Generator 的洗髓经（10002），参考版本为 `8fad4eb8b52fa435bc656e7731ccbf40d6d41126`，保存在 `参考数据.json`。刷新脚本为 `scripts/update-xisui-reference.ps1`。

秘籍固定为17本，涵盖普渡四方、韦驮献杵、横扫六合、大狮子吼、擒龙诀，仅显示已选项并锁定。大狮子吼减CD5秒、减CD10秒及命中回复1点禅那的条目保存在 `补充秘籍.json`。

常规奇穴固定为醍醐灌顶、禅慧、心诤、系珠、摩诃守御、立地成佛；混池固定大善、涅果、禅语。均提供图标和效果说明，旧缓存及方案切换也恢复该模板。

普渡一次为一段内功（17641）及一段武伤（19090），不计17642的额外内功；醍醐一次有两段伤害，但资源与减充能仅处理一次。韦驮按消耗禅那数量区分，排除易筋经专用271附加伤害。拿云式、守缺式、捕风式不纳入洗髓招式。

## 属性与装备

配装器复用公共界面：方案推荐顶部将推荐方式、装备范围、橙武品级、最低御劲集中在左侧，莫问阵、加速增益及团队增益开关集中在右侧。装备部位选择与明尊保持相同样式。普通/英雄快捷范围分别为1110～1120、1170～1300品。

洗髓的智能对比及设置入口已开放。勾选后，装备、附魔和大附魔下拉同时显示DPS差值与收益百分比；百分比基于当前配装，计算走洗髓自身的伤害与循环入口。方案推荐继续按洗髓3/4/5档自适应循环和同一御劲要求比较，保持洗髓独立的技能及资源规则。

主副T读取洗髓17885/2、29938/2气劲，体质转阳攻/破防系数分别为1649/459与546/154，按1024换算。切换后立即更新DPS，且不受启用增益总开关限制。心法基础、阳性攻击和体质转内防独立结算。

50级装备、附魔、镶嵌、五彩石及导入导出复用公共配装逻辑。水特效武器按门派显示；元气主动破防腰坠按15/180平均收益计算。洗髓橙武为降魔境，1110、1170、1240品均可精炼8级，原始属性、武伤及体质/外防/内防孔保存在 `橙武装备.json`。旧洗髓方案借用的明尊橙武按同品级修正，保留精炼和宝石等级；橙武触发效果仍列为未计入。方案推荐默认不选橙武，选择719、1110、1170或1240品后，仅该品级的洗髓橙武独立加入武器候选，不受普通品级范围限制，与普通武器按洗髓面板和3/4/5档循环比较，不强制最终装备。固定当前洗髓橙武时可继续推荐其他部位。

药食、阵眼和公共团队增益受总开关控制，一键团队增益沿用已记录的公共预设；明尊圣浴常驻不纳入洗髓。自身循环立地减防15%可与团队额外来源15%叠加至30%，同一来源不重复叠加。

## 自适应循环与推荐

719品降魔境及明尊圣辉月雪另存于公共的 `压缩橙武装备.json`，来源为考拉原库50级压缩数据。同一装备ID在130级版本为42500品，压缩后为719品。该档橙武作为入库下限的例外，武器下拉沿用橙武不受品级范围限制的规则；其他装备仍从1110品起收录。

网页已接入“自适应理论循环”，根据装备及已启用增益的实际加速调用3、4、5档300秒循环，记录延迟40ms。技能次数与动态增益状态保存在 `循环记录.json`，DPS按当前装备、气劲、目标和增益重新结算。

方案推荐分别比较三档，统一最低御劲要求与配装器筛选范围。加速达到模拟档位或更高即可参与，不为压低加速而降品；品级只限定候选范围，同伤害再优先高品级。高档配装可以沿用装备模拟低档循环，应用后按实际档位自适应计算。附魔保留当前数值档位并排除御劲附魔，药品与食品增强须选择同属性，五彩石固定，阵眼及团队增益按选项参与。

已确认的模拟规则：

- 战前大狮子吼、擒龙诀、金身；不额外计算战前大狮子吼的禅那。
- 大技能CD不随加速变化；心诤引导随加速缩短，完整施放后终结扫击并回复3点禅那。
- 禅语维护优先级最高，最低1点禅那且大狮子吼CD就绪即可补；心诤引导不打断，期间失效则结束后优先补。
- 醍醐、心诤须在有效大善3层后施放。常规普渡获得立地准备后接韦驮，不强制等待3点禅那；仅快速叠大善时允许无立地准备的三豆韦驮。
- 已有自身立地准备时普渡不重复获取；金刚日轮首次横扫后按持续存在处理。
- 擒龙为2层充能、每层25秒，系珠含固定秘籍后持续15秒。醍醐每次减少最大CD的20%，先扣当前恢复层，溢出转下一层。
- 韦驮秘籍只回1点，不触发擒龙额外回豆；擒龙期间普渡按涅果1点加秘籍1点，共回2点，受3点上限限制。

详细依据见 `奇穴效果说明.md`、`禅那规则.md` 及相关测试。
