# 降魔境橙武特效核对

机制核对日期：2026-10-26。独立试算结果归档于工作区洗髓工具的橙武实验目录。2026-10-27已将确认的3、4、5档固定起手主动＋被动记录接入本地网页自适应循环、智能对比与方案推荐；装备降魔境时自动启用，换下后恢复普通模板。

## 主特效：主动爆发

- 50级试做橙武对应技能1855的9级；719品压缩橙武对应1855的8级。
- 开启时增加3点禅那，受当前3点上限限制。
- 获得降魔境Buff：1920的8级或9级，两者本次核对的属性相同。
- 持续时间为24次×4帧÷16帧/秒＝6秒。
- 窗口内韦陀献杵命中目标后增加3点禅那。1、2、3豆分支均检查1920的8级/9级，不只三豆分支。
- Buff设置临时秘籍2862/1，其`SkillRecipeType=233`、`DamageAddPercent=922`，为韦陀对应伤害增加922/1024≈90.0391%的招式增伤。
- 这是招式增伤区间的原始值，后续计算应按同区间叠加规则处理，不能给最终伤害再独立乘1.9。
- 韦陀的内功伤害3848、3849、3850的RecipeType均为233；武伤子技能19090的RecipeType为19090，神兵25794也不属于233。不能把上述922统一加给武伤或神兵。
- 原始装备描述规定：秘境、主城、试炼之地、帮会领地使用主动触发，调息50秒；其他可触发场景存在随机主特效，最多30秒一次，名剑大会不能触发。木桩模型使用主动50秒口径。
- 30秒内部锁（2584/1以及5079）与场景主动50秒不是同一个概念，不能据内部锁把主动CD改成30秒。

## 独立被动：韦陀献杵·神兵

- 伤害技能25794/1，阳性内功伤害，可会心，附带基础威胁2000。
- 触发事件1950：`EventType=Cast`、`EventSkillID=233`、`Odds=307`。
- 即每次施展韦陀独立判定307/1024≈29.9805%的额外伤害，按施展次数处理，不能按内功、武伤等伤害条数重复判定。
- 此被动独立于6秒主特效，主动未开启时也存在。
- 25794脚本没有回禅那操作，不能让神兵额外伤害再次触发主特效回3点禅那。
- 本次读取的事件与伤害脚本未设置该被动的额外内置调息；`nChannelInterval=50`属于伤害系数参数，不是被动触发CD。
- 考拉本地公共技能缓存`SKILLS[0][25794][25794][1]`的原始伤害部分为`rand*2 + int(solar_attack_power*0.032200749674669384)`，其后再按原式逐层取整并结算增伤、破防、防御、会心、等级压制、无双等。
- 客户端脚本的表虽含`nDamageBase=20`，实际AddAttribute读取的是未设置的`nDamage`；考拉解析结果也没有固定20点。不能擅自给该被动再加20点基础伤害。

- 主动窗口结束后恢复原先的常规组合规则。
