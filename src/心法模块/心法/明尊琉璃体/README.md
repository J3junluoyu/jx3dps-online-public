# 50级明尊琉璃体

## 使用

在仓库根目录安装依赖后：

```powershell
pnpm dev
pnpm test
pnpm typecheck
pnpm build
```

开发地址为 `http://localhost:3000/`。沿用原项目入口、Redux方案、配装器、奇穴/秘籍抽屉及结果组件，项目仅保留明尊心法模块。构建输出到原项目的 `build/`；`pnpm build:local` 使用原本地模式。原有`:mingzun`命令作为兼容别名保留，不再维护独立入口和打包配置。

首次进入时自动把旧独立页面的有效属性、配装、气劲、秘籍及技能次数转为原项目方案；已有原项目方案时不会覆盖。旧数据会先经过计算校验，无效缓存不会写入原项目方案，原缓存键仍保留。

主T/副T在基础设置中直接切换并立即重算，默认副T；旧“无气劲”方案按副T使用。技能次数、统计时长和其他增益由单独的“技能次数 / 增益”入口设置。

赤日轮、烈日斩、幽月轮、银月斩、净世破魔击、生死劫、驱夜断愁仅提供伤害和会心秘籍，显示为“伤害X%”“会心X%”。烈日斩额外保留“原地伤害10%”，净世破魔击额外保留“回月魂20点”。戒火斩不提供秘籍选择。来源未列出的伤害或会心秘籍不补造。旧选择按原始ID或完整名称恢复，移除项不再参与计算，每招仍最多四本；回月魂不自动增加手动技能次数。

原项目依赖130级品级与附魔容量的加速规划、一键附魔及循环优化算法暂不对明尊开放。手动精炼、镶嵌、附魔、三层五彩石及五彩石对比继续使用50级数据。收益图表也使用同一套Generator取整规则；会心曲线从装备会心为零时的实际会心起算，无法扣除属性的置换显示为空。

“附魔收益”按用户指定，破防、会心、无双、攻击、体质、会效分别额外增加72点后比较DPS差值。通用攻击和破防同步增加内外功：大漠刀法计入外攻、外功破防收益；独立武伤按考拉的外攻百分比和额外外攻两项结算，没有这两项时不计基础外攻，仍计入外功破防收益。体质会重新计算心法及气劲转换。实际配装附魔仍按各自来源数值结算。

## 来源与取值

- 等级体系、属性换算：[新50级技能属性变化及概述](https://www.jx3box.com/bps/109665)、[苍生铸世属性数值体系](https://www.jx3box.com/bps/109685)。文章为测试服资料。
- 心法、气劲、技能、持续伤害、秘籍和奇穴：[Generator](https://github.com/J3junluoyu/Generator/tree/8fad4eb8b52fa435bc656e7731ccbf40d6d41126/kungfus/ming_zun_liu_li_ti)，提交 `8fad4eb8b52fa435bc656e7731ccbf40d6d41126`。
- 参考数据只导入 Generator 的 10243 心法子树，没有克隆 Generator。`scripts/update-mingzun-reference.ps1` 可重新在线读取最新记录；更新后需重新核对数值和测试。

明尊气劲优先使用 Generator 的整数值，不使用文章中较早的近似值，不把副 T 与主 T 气劲叠加：

| 来源                         | 体质转阴阳攻击 | 体质转内功破防 | 体质转内功会心 |
| ---------------------------- | -------------- | -------------- | -------------- |
| 心法固有                     | 163/1024       | 0              | 0              |
| 副 T 明尊（29938，4级）      | 610/1024       | 184/1024       | 0              |
| 主 T 明尊·宿敌（17885，4级） | 1828/1024      | 549/1024       | 0              |
| 极本溯源气劲（上述气劲7级）  | 与4级相同      | 与4级相同      | 90/1024        |

极本溯源固定启用，提供 461/1024 的无视防御，主副T气劲自动使用7级的90/1024体质转会心。无气劲时不添加体质转会心。气血以 Generator 的基础值4136、体质转基础气血10、心法体质额外转气血2253/1024、基础气血加成51/1024分别结算。主属性的裸身值为体质18、元气17、根骨18、力道17、身法18。

## 固定奇穴格式

| 层级   | 可选奇穴                        |
| ------ | ------------------------------- |
| 第一层 | 圣浴明心（固定）                |
| 第二层 | 怜世人（固定）                  |
| 第三层 | 极本溯源（固定，同步主副T气劲） |
| 第四层 | 净体不畏 / 无量妙境             |
| 第五层 | 妙镜惊寂 / 五明乐见             |
| 第六层 | 纵遇善缘 / 光明心 / 孤月无心    |

第四至六层各选一项。独立混池最多选择3项：净身明礼、血泪成悦、驱夷逐法、炽炎镇恶、月尽天明、斩火。名称使用Generator原名。旧缓存会迁移为此格式，保留有效选项和装备；失去前置奇穴的技能次数会清除。

网页首次打开时，默认选择圣浴明心、怜世人、极本溯源、无量妙境、五明乐见、光明心，混池为血泪成悦、驱夷逐法、月尽天明。配置集中记录在`默认奇穴.ts`，两个内置GCD循环共用。已有本地保存的有效奇穴选择继续保留，用户仍可通过奇穴设置调整。

属性转换使用 `C(l)=330 (l≤30)`，否则 `33*l-660`。会心、破防、无双等使用线性换算，闪避、防御、招架和化劲使用非线性换算。全能每点转1.22无双和1化劲，完全不产生破招。木桩为51至54级，防御点数分别为2791、3841、6399、6592。

明尊基础GCD为1秒（16帧）。角色属性的“加速”同时显示加速百分比与实际GCD，例如`15.14% 0.8125s`。GCD沿用原项目郭氏加速和帧数向下取整，按未四舍五入的加速等级计算；无额外加速时，50级各档起点为0、10、682、1452、2340，对应1、0.9375、0.875、0.8125、0.75秒。显示增益后面板时同步使用增益后的加速。

配装器属性预览将加速与GCD并排显示，下方提示下一档GCD及尚缺的加速点数；悬停可查看下一档所需总点数。提示按当前预览属性计算，切换增益后面板时同步更新；达到普通加速最高GCD档位后显示“已达最高GCD档位”。

角色属性不显示装分；体质行同时显示朝圣言运功层数，为基础体质除以95向下取整，最多100层。基础体质包括裸身、装备和已生效的固定体质及全主属性增益，不包括体质百分比加成；显示数值随增益面板开关更新。这些层数只作反馈，不自动追加朝圣无双增益。伤害及收益相关数值统一显示两位小数，计算和排序保留原始精度。

五彩石三层选项在属性名后显示实际数值，体质加成换算为百分比。页面右下角菜单仅保留问题反馈、新手教程、清空缓存。单点收益图表移除武伤项目。

御劲与御劲减伤分别换算：御劲（降低被会心几率）使用原项目系数19.218，御劲减伤（降低受到的会心伤害）使用9.518。50级分别以19025.82、9422.82为线性换算分母；玉露酒92点增加约0.48355个百分点御劲、0.97635个百分点御劲减伤。面板“御劲”只显示前者，后者单独保存在`toughnessPower`，不参与输出伤害计算。考拉`base/attribute.py`中名为`toughness`的属性使用9.518，校验数据将其映射为`toughnessPower`，避免与面板御劲混用。

## 计算边界

“技能次数 / 增益”入口放在基础设置标题右侧；“增益详情”放在秘籍、奇穴、气劲选项下方整行。

增益详情在药品辅助上方提供冰心、田螺、毒经、无界、万灵、气纯、莫问及T阵八种阵法，沿用原阵眼组件、单选和方案字段，可清空。只计算普通小队成员收益，受“启用增益”总开关控制。毒经仅临时破防按50%覆盖，万灵仅临时会效按96%覆盖；其余效果100%覆盖、叠层取满层，气纯五阵为5层。T阵由用户补充，只有基础体质提高3%，按既有郭氏百分比规则换算为31/1024，与其他体质百分比加算，不补造考拉气劲ID。

原始气劲保存在`阵眼数据.json`，来源与心法参考数据为同一考拉提交。冰心使用952及955，不计阵眼自身破防和会心；田螺使用3307及3310，不计阵眼自身的32800无双。毒经不计2513阵眼自身攻击，气纯不计949阵眼自身攻击。莫问对应考拉16151组，原始阵名与属性不一致，显示名称沿用原项目的“莫问阵”，原始记录不改写；五阵严格使用9492原始内功会心，不补造外功会心，排除阵眼自身的9486会效及9489破防。田螺3307的自身受到外功伤害降低不会作为输出易伤应用。

会心率气劲按万分比、会效及额外无双按1024制计算，明确区分内功与外功。基础攻击、基础破防先应用阵法百分比，再加体质转换的额外值；主T、副T气劲提供的额外破防不会被毒经阵放大。`scripts/verify-mingzun-formations.py <source_cache>`使用考拉原Python数学模块生成`阵眼算法校验.json`，覆盖无阵及八阵在主副T两态的18组面板与驱夜、大漠、武伤伤害。

角色属性标题旁增加“圣浴常驻”开关，写入团队增益“圣浴明心（常驻）”，覆盖率固定100%。根据当前生效的基础体质计算朝圣层数，再取十分之一向下取整，上限10层，每层无双41；层数会随换装、固定体质增益更新，百分比体质不重复进入基础体质。与完整朝圣“圣浴明心”互斥，切换开关与团队增益列表共用同一方案记录。实际伤害和面板计算都会重新计算层数，避免旧缓存或装备对比沿用过期层数；仍受“启用增益”总开关控制。

驱夜断愁提供伤害3/4/5%、会心3/4/5%六项秘籍，每招最多选择四本。秘籍原名、ID和系数保存在`驱夜断愁秘籍.json`，取自同一考拉版本的通用驱夜记录（10242/3979）。明尊怜世人导出式未带这六项秘籍变量，适配时仅补齐同名招式的31/41/51除以1024伤害加成和3/4/5%会心加成，分别在原增伤区及会心率通道生效；明尊原始基础伤害、攻击系数及逐层取整保持原式。

明尊驱夜断愁不计算背后30%增伤，单技能和基础循环使用相同规则。五明乐见及所选秘籍仍在各自通道生效；数值回归检查使用考拉原Python算法结果，覆盖无秘籍及秘籍与五明同时生效的状态。

装备输入为装备、镶嵌、附魔提供的原始合计属性，不能直接填带心法的游戏面板。内功/外功攻击、破防和专属双会分别录入；通用双会同时作用于内外功。

按1110品及以上筛选后，当前有163件PVE装备：56件带加速的明教/通用防御装、107件精简内功装。防御装必须在绿字属性中含加速；精简内功按Generator的“精简”门类和“内功”类型筛选，涵盖防具、首饰及暗器。近战武器仍使用明教武器。保留项的装备ID与属性保持一致。旧配装中已移除的装备会清空对应槽位；有效装备、精炼和镶嵌会保留。

装备名称后缀按原始绿字属性显示分配：防御装使用“内外”“内外速”“内速”“外速”等；精简内功装显示“会心·无双”“破防·无双”“会心·会效·无双”等，并标注“精简内功”。基础护甲、镶嵌和附魔不改变后缀。

配装器选项的属性括号额外以红色“体”标记体质镶嵌孔，按原始孔位类型判断，与镶嵌等级无关。当前56件防御装备中28件带体质孔，其余28件不标记；装备自身的体质属性不作为判断依据。

原始参考库含178种永久附魔和完整的1464条陆级五彩石记录。五彩石导入不要求带体质或防御属性，避免遗漏通用内功和阴阳内功攻击石。

选择器移除仇恨、化劲、治疗、元气、力道、根骨、身法及全主属性相关选项，附魔还会排除名称含“归正”以及武器伤害（武伤）类记录。五彩石仅提供陆级，攻击属性只保留通用内功或阴阳内功，外功及其他内功类型会整颗排除。五彩石还会排除内外功防御、御劲、闪避、招架、拆招、内力恢复及守御、大御、守护、铁壁等相关属性或效果。按用户指定，“彩·守护·固本·健体(陆)”作为特例保留。同名且属性完全相同的记录合并展示，旧来源ID会映射到保留项。当前可选77种附魔、66种陆级五彩石。旧配装会清除已移除的附魔和五彩石，保留有效装备、精炼及镶嵌。

五彩石采用三层属性选择：选择第一层后，只提供确实存在的第二层搭配，再根据前两层筛选第三层。选满三层后自动匹配石头，显示名称及各项数值；修改上层会清空后续层和原匹配结果。完整选择及未选完的有效前缀均可在刷新后恢复。

“彩·守护·固本·健体(陆)”来源ID5599。Generator仅列出全主属性46、体质加成81/1024两项；选择“全主属性 → 体质加成”即可匹配，第三层显示“无第三层属性”。体质加成以百分比显示约7.91%，内部使用精确值计算。

例如“彩·无双·急速·琉璃(陆)”提供无双52、加速104、阴阳内功攻击208（Generator来源ID为5754、5790，合并展示为5754）。选择“无双 → 加速 → 阴阳内功攻击”即可匹配。通用内功及阴阳内功的攻击、破防、会心和会效分别汇总到对应装备属性。

支持12个装备槽、精炼、逐孔镶嵌、附魔、五彩石及套装常驻属性。原始数据包含“测试用”物品，保留名称与ID。在原配装器点击“保存并计算”会覆盖手动输入合计值，可继续修改。

精炼仅对magic属性增加 `ROUND(原值*n*(0.7+0.3*n)/200)`。镶嵌按Generator的`EMBED_COF`逐孔向下取整，包含`1355/27800`版本压缩因子。套装达到件数后只添加一次对应阈值属性。五彩石按已满足激活条件计算。技能秘籍、触发特效和疗伤成效尚未应用，选择器会明确列出这些未计入效果。更新数据可运行`scripts/update-mingzun-equipment.ps1`，其固定提交需与心法数据保持一致。

孔位按Generator原始顺序保留，属性分类缺失时使用原始属性ID。当前163件装备中20个仇恨孔的分类为空、数值为0，仍会显示“仇恨孔”，不会推测或填造其仇恨收益。旧镶嵌配置会按原属性迁移到正确的孔位，避免恢复前置孔后等级错位。

技能使用固定提交的50级 Generator 伤害表达式，由仅支持数字、变量、四则运算与 `int` 的解释器计算。不会执行表达式文本中的代码。命中伤害、会心伤害逐步取整，期望伤害按最终会心率加权。`rand=0.5` 与 Generator 的期望波动约定一致。

武伤与大漠刀法的算法按考拉桌面端`assets/raw/skills.py`及`base/attribute.py`核对。`physical_attack_power_addition`表示外攻百分比加成，默认0；大漠刀法使用完整外攻`int(基础外攻×(1+百分比))+额外外攻`，独立武伤使用`int(基础外攻×百分比)+额外外攻`。导出记录中的`source_attribute`为元数据，其修正已进入公式，不在运行时重复叠加。当前可选增益没有外攻百分比或体质转外攻，因此基础外攻增加时独立武伤不变；以后存在这类增益时仍按考拉公式生效。

`考拉算法校验.json`由考拉原Python属性类和表达式类生成，覆盖8种状态、8条武伤与大漠刀法，逐项校验最小/期望/最大武器浮动、命中/会心，共432个伤害结果。`scripts/verify-mingzun-koala.py <source_cache>`可复算：缓存需提供同一提交的`base/{attribute,constant,expression,utils}.py`、`tools/lua/enums.py`及`assets/raw/skills.py`（缓存名`assets_raw_skills.py`），不需要克隆仓库或安装Qt。脚本先确认9条公式与本地参考一致，再用考拉Python数学模块生成对照数据；测试同时验证公式哈希与版本。

戒火斩按最终体质每95点选择一档，直接使用Generator对应档位的原始公式，最高使用其提供的第11档（950体质起），不再向上外推。该边界表示当前资料可计算的范围，不代表已经实测确认游戏上限。基础伤害不随档位放大。技能附带武器伤害独立统计，月破按单次命中、DOT按单跳统计。

内置“0.8125GCD循环”和“0.75GCD循环”，均统计300秒，分别使用用户提供的两组数据。实际GCD为0.8125秒（加速1452～2339）或0.75秒（加速2340及以上）时，自动选择对应循环，界面名称和实际计算共用选择结果；计入已启用增益的加速，按原始点数判断，不按显示百分比四舍五入。原“明尊基础循环（300秒）”方案按当前档位切换；“明尊自定义命中次数”和“迁移的明尊命中次数”不再列为可选项。同档位保存的自定义次数仍可使用，跨档后切换为对应预设。

循环以10项输入推导完整17项：常规月破、驱夷五明日破、驱夷光明相日破均等于驱夜断愁次数，驱夷光明相月破为其2倍，无量妙境为其15倍，驱夷月破保留0次。月破输入施放次数，每次换算为3段命中，DOT按跳数，无量按阴阳合计触发次数。武伤总次数由日轮三段、烈日斩、银月斩、日破次数、月破命中段数及驱夜次数相加；戒火斩、DOT、无量、大漠刀法不额外产生该项武伤。

“驱夷”行使用驱夷逐法条件；“五明”和“光明相”行、无量妙境、驱夜断愁使用五明乐见的10%增伤；“光明相”行同时使用耗灵技必会心。状态按行应用，不受全局光明相/驱夷开关覆盖。日破及驱夜附带200%武伤，其他武伤为100%。0.8125循环武伤388次拆为74次200%和314次100%，对应47次普通200%、27次五明200%、260次普通100%、54次五明100%；0.75循环武伤407次拆为79次200%和328次100%，对应52次普通200%、27次五明200%、274次普通100%、54次五明100%。驱夜独立武伤取同版本考拉10242/3979/19055/9原始记录，与明尊日破武伤公式完全相同，校验脚本检查其公式及会心表达式一致后复用；明尊25355/4480的内功伤害仍使用自身原式，不添加背后增伤。生成循环时推导武伤总次数，伤害计算只对武伤行分配一次，不再从其他技能重复追加。武伤与大漠刀法使用外功公式及外功破防，体质转内功破防不影响这两项。修改基础循环的次数或时长会保存为独立的自定义循环。

全部16个可选奇穴使用魔盒原始技能表中的对应IconID，映射及来源版本保存在`奇穴/图标.json`。按当前奇穴ID匹配，包括新版无量妙境、纵遇善缘、光明心、五明乐见及炽炎镇恶；不再统一使用太极占位图。

## 考拉增益适配

新增仙王蛊鼎（每层无双26）、圣浴明心版朝圣言（每层41）、寒啸千军（团队每层3）及号令三军（一鼓每层34），均沿用原团队增益的层数、覆盖率、启用和持久化控件。仙王蛊鼎默认覆盖率25%，寒啸千军默认50%，仍支持手动修改。寒啸千军的考拉buff原记录为施法者自身每层15，原记录保留，团队效果按同版本技能说明的3点单独接入。
